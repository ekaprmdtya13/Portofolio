# Personal Portfolio Website

A responsive and modern personal portfolio website built to showcase my projects, skills, and professional experience.

## 🚀 Features

- Fully responsive design
- Project showcase with details and live demos
- About Me and Contact sections
- Smooth animations and transitions
- Dark mode (optional)

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** GitHub Pages / Vercel / Netlify

## 📦 Installation

```bash
git clone https://github.com/ekaprmdtya13/Portofolio.git

cd Portofolio

# Open index.html directly or use a live server extension
````
